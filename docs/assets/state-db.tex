%
% ===================== SEMANTIC LEDGER =====================
% object           class    meaning                                producer / consumer
% ---------------- -------- -------------------------------------- -----------------------------
% s_* (6 nodes)    stage    pipeline stage box, write role         collect, filter, gate_select,
%                                                                  dedup, meta_qa, collectors
% r_* (5 nodes)    stage    same stages in their read role         filter, gate_select,
%                           (dup across sides is intentional)      review_server, dedup, meta_qa
% f_items          fam      items + item_runs tables: episode      W: collect,filter,dedup,
%                           pool, lifecycle cache + carry-over         gate_select (+meta_qa,
%                                                              R: filter,gate_select,review  review writeback)
% f_dedup          fam      dedup_items + dedup_clusters:          W: dedup,meta_qa
%                           clusters, centroids, verdicts          R: filter,dedup,gate,meta_qa
% f_source         fam      source_state: seen URLs + health       RW: collect
% f_kv             fam      kv: x_nitter_health / reddit_token /   RW: collectors
%                           weibo_cookie JSON blobs
% dbbox            band     the single sqlite file (WAL)           container for 4 families
% bus              mdot     branch point of shared dedup_* read    w12 trunk -> w13 tap
% w1..w15          wire     data-flow edges; left = writes into    see vaudit via=/endpoint=
%                           families, right = reads out of them
% hue map          -        cards colored per family (items=vteal,
%                           dedup=vviolet, source=vorange, kv=vgold);
%                           stages neutral vgray (same role both sides)
%
% ===================== GEOMETRY LEDGER (cm) =====================
% stage boxes    w~2.3 h~1.08 (text width 2.0, min height 1.05)
% left col  c_x=0.80  x~[-0.35,1.95]; y: collect 9.50, filter 8.00,
%          gate 6.50, dedup 5.00, meta_qa 3.50, collectors 1.85
%          (pitch 1.5 / 1.65 > box-h + crowd 0.35)
% right col c_x=13.25 x~[12.1,14.4]; y: filter 9.60, gate 8.10,
%          review 6.60, dedup 5.10, meta_qa 3.60 (pitch 1.5)
% family cards  x[5.6,10.7] c=8.15, w~5.1 h=2.05 (min height, dedup
%          title wraps to 2 lines -> uniform min-height keeps class=fam
%          equal), pitch 2.50:
%          items y[7.55,9.60], dedup y[5.05,7.10],
%          source y[2.55,4.60], kv y[0.05,2.10]   (gaps ~0.45)
% dbtitle (8.15,10.10) inside band; dbbox fit(inner sep 10pt)
%          ~x[5.25,11.05] y[-0.30,10.65]
% routing    vertical card stack => every card west/east edge reachable
%          by a straight line crossing only dbbox border (via=dbbox).
%          exceptions (declared):
%          * w2 collect<->source loops the far-left channel x=-0.85,
%            re-enters at y2.62 inside the container's west margin
%            x5.45 (a direct diagonal would cross all five
%            items/dedup-bound left wires);
%          * w12 dedup->r_filter + w13 dedup->r_gate share an
%            orthogonal trunk at x=11.55 with bus tap (11.55,7.7);
%            the vertical crosses w10,w11 (wire-wire, unaudited) —
%            K(2,3) bipartite on the east face cannot be planar.
% wire labels  lab style (white fill) centered ON their own wire at
%          x=3.6 inside the 3.3cm left channel, declared via=lcN on
%          that wire; right channel too narrow -> read semantics live
%          in the mean-box mechanism line.
% ==================================================================
